# Contract conformance matrix

This matrix records **current evidence**, not intended architecture. A schema that passes JSON Schema validation does not make a producer or consumer conformant. CaveSharp path coverage is grouped by subsystem here; the preceding [Phase 2 alignment](./organ_status.md#phase-2--organ-to-contract-alignment) gives the exact file-by-file mapping for all 95 source/project paths.

## Conformance levels

| Level | Meaning |
|---:|---|
| **0 — Unaligned / unverified** | No demonstrated canonical contract message or validator at the component boundary. Related source alone does not raise this score. |
| **1 — Legacy overlap** | A legacy payload overlaps contract fields, but required envelope/fields, semantics, or validation are missing. |
| **2 — Adapter-conformant** | A named adapter produces/consumes canonical messages and passes the applicable contract tests, but the source component itself has not fully adopted the contract. |
| **3 — Conformant** | The runtime boundary emits/accepts the contract shape and validates it with automated conformance tests. |

## Deprecation / redesign disposition

- No component is marked for deprecation solely from this matrix. Multiple similarly named CaveSharp subsystems require ownership review before any consolidation.
- The legacy flat WebSocket payload should be **compatibility-adapted**, not removed, until consumers migrate and a deprecation window is agreed.
- Shared-file telemetry/event paths are reserved rather than active. Do not build an adapter around them unless file exchange is deliberately selected as a supported transport.
- The current Python `OrganRequest`/`OrganResponse` remains an in-process API; redesign is not required to make it the wire `command_contract`.

## Evidence and next gate

The viewer and Hacker-Lab snapshot/world consumer adapters now validate Spine messages against the canonical schemas and have API/fixture tests, so those consumer rows are level 2. No live full-engine producer or level-3 runtime boundary is verified; module/event and command paths remain unactivated.

Raise a row to level 2 only when its adapter and conformance tests pass; raise it to level 3 only after the live component boundary validates/emits the contract. Update this matrix with the exact test and source revision used for each rating change.
